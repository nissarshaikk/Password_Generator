# 🔐 Password Generator

> Generate strong, secure, and random passwords using Python.

## 📖 Overview

This Password Generator is a Python-based command-line application that creates secure passwords using a combination of:

- 🔤 Uppercase Letters
- 🔡 Lowercase Letters
- 🔢 Numbers
- 🔣 Special Characters

The project helps users generate strong passwords to improve account security.

---

## ✨ Features

| Feature | Description |
|----------|-------------|
| 🔒 Secure Passwords | Generates strong random passwords |
| 📏 Custom Length | User chooses password length |
| 🔄 Multiple Generation | Generate unlimited passwords |
| ⚡ Fast | Instant password creation |
| 🖥️ CLI Based | Easy-to-use terminal interface |
